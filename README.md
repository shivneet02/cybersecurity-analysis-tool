# cybersecurity-analysis-tool
A simple project for cybersecurity analysis and tracking security issues.
## Project Description
This project is created to practise basic
cybersecurity tasks and manage security issues.

## Project Goals
- Learn GitHub version control.
- Manage project changes.
- Track cybersecurity issues.
- Understand basic firewall security.

## Project Features
- Firewall configuration checks.
- Security log analysis.
- Vulnerability tracking.

## Tools Used
- GitHub
- Git
- Freshworks
